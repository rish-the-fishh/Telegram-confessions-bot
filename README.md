# Telegram-confessions-bot

This is a personal project I'm working on for fun that I'm planning to launch to my university chat. It allows users to post their confessions with a bot as their medium to do so. They can also choose to confess something privately with someone while still maintaining that anonymity, provided the person they want to chat with is a user themself. I'm orchestrating the whole thing using a burner account. This will be fun to watch indeed.
